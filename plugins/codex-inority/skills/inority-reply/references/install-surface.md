# Codex Inority Reply Hook Surface

Reply formatting is activated by the plugin root rather than a skill-local installer.

- Hook registration: `../../../hooks/hooks.json`
- Hook implementation: `../../../scripts/inority-context.mjs`
- CLI template: `reply-format-cli.md`
- Markdown template: `reply-format-md.md`

Install or update the `codex-inority` plugin through its configured marketplace,
then start a new thread so Codex reloads plugin hooks.
