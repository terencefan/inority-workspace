#### 吞吐量

> [!NOTE]
> 回答单位墙钟时间内成功完成的请求数；越高越好，作为主判定指标。

```katex
R_j=\frac{N_j}{T_j}
```

其中，$N_j$ 为第 $j$ 轮成功请求数，$T_j$ 为连续有效窗口秒数；连续 3 轮，每轮不少于 300 秒。
