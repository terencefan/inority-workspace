---
name: oneone
description: 向用户输出一对一状态卡（职责/目标/进度/待裁）。supervisor 定时唤醒、compact 压缩后重对齐、或用户主动输入 /oneone 时使用。
---

输出一张面向用户的状态卡，四段固定结构，内容必须取自当前会话的真实上下文：

1. **职责** — 本会话被指派的任务是什么。
2. **目标** — 终态判据：做到什么程度算完成。
3. **进度** — checklist：`- [x]` 已完成 / `- [ ]` 进行中 / `- [ ]` 待办；含关键数字与最新状态。
4. **待裁** — checklist，格式与进度一致：所有等待用户裁决/批准/拍板的事项，每项一行 `- [ ]`，写清决策点与可选项；没有待裁事项时写「- 无」。

要求：

- 卡片式简洁输出，不展开长篇叙述。
- 待裁项必须真实来自会话中用户尚未拍板的问题，不得虚构或凑数；已裁决的事项移出待裁、转入进度。
- 「下一步」不再作为独立段落——接下来的动作并入进度条的进行中/待办项表述。
- 无在途任务时如实输出"当前无在途任务、待命中"，不得虚构进度。
- compact 后调用时，先从压缩摘要恢复任务状态，再输出。
