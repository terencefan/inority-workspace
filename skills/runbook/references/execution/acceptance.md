# Acceptance Phase 子文档

这个文件是 `runbook` 主 skill 的按需加载子文档，用于单个编号项的 `#### 验收`。

## 边界

这个 phase 只拥有：

- 当前编号项
- 该项的 `#### 验收`

不能：

- 执行该项的 `#### 执行`
- 继续跑到 `N+1`
- 勾 `## 最终验收` checkbox
- 重写计划
- 临时编新检查项

## 开始前重读

- authority runbook 路径
- 当前编号项
- 该项的 `#### 验收`
- 该项的通过条件
- `## 最终验收` 中与该项相关的 checkbox（只读参考）
- 停止规则

## 验收纪律

- 严格按 authority 中已写好的验收块执行
- 把实际结果与通过条件逐项比对
- 如果任何一条检查未通过，立即停止，不要继续往后跑
- 失败时必须明确回报：失败项、预期、实际、以及需要回规划态
- `runctl` 写回必须与其他 lane 串行

## 停止条件

出现下面任一情况，立刻停止并回规划态：

- 验收未通过
- 通过条件不清楚
- 命中停止条件
- 出现 authority 之外的新 blocker / 新事实

## 完成标准

- authority 已写回
- 对应验收签名 heading 已更新
- 证据真实且与当前 item 对齐
- 未提前勾选 `## 最终验收`
