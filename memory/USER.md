## 文档写作

- blockquote 保持简洁，优先只写一句。
- blockquote 必须写多句时分行表达。
- 编写文档时不使用分号。需要用分号分隔的并列内容改写为列表。
- 文档标题只使用文字，不添加 `x.y.z`、`1.2.3` 等多级数字序号。
- 更新飞书文档时，如果漂移检查仅发现 revision 变化、线上正文没有变化，默认直接刷新基线后发布，不再询问合并路径。若线上正文确有变化，仍先生成差异并确认合并方式，避免覆盖人工编辑。
